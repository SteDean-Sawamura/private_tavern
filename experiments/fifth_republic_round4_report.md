# 第五共和国剧本 第四轮五回合推演实验报告

## 实验背景

本轮测试（Round 4）在 Round 3 基础上针对三类上下文逻辑问题进行了 prompt 层面的优化：

| 问题类型 | Round 3 表现 | 优化措施 |
|----------|-------------|---------|
| 时代错误 | T4 出现手机、短信（1979年不存在） | 注入 world_background + 时代约束规则（Stage 1 & 2b） |
| 行动篡改 | T1 "回办公室"→明洞街头；T3 "前往南山"→打电话 | 新增"行动不可篡改"规则（Stage 1） |
| 剧情过密 | 1000字内塞入5个组织10个NPC，信息瞬间传遍 | 数量约束（关键事件≤3、NPC≤3）+ 信息传播延迟规则 |

改动文件：`engine/prompt_builder.py`（纯 prompt 文本修改，无代码逻辑变更）

## 上下文逻辑连贯性分析

### 因果链追踪

```
T1: 发现情报 → 金载圭"忍耐的终点" + 预备队异常调动 + 宫井洞晚宴
     ↓
T2: 联络卢泰愚 → 用T1发现的情报作为谈判筹码 ✓
     卢泰愚"等宴会结束再看" → 预留后续联络伏笔 ✓
     ↓
T3: 前往南山调查 → 发现金载圭频繁调阅卷宗（印证T1的异常信号） ✓
     被秘书官注意 → 为T4的监视哨埋下伏笔 ✓
     ↓
T4: 秘密会议 → 讨论T3的监视哨 + T1的调动记录 ✓
     尹昌洙分析三方博弈格局（中情部/保安司令部/云岘洞） ✓
     ↓
T5: 宫井洞枪声 → T1预言的宫井洞晚宴终于爆发 ✓
     中情部车辆在门外（T3秘书官汇报的延续） ✓
     侦察队出发（T4会议决策的执行） ✓
```

**五回合的因果链完整连贯**，每一回合都建立在前面回合的信息基础上，没有出现断裂或矛盾。

### 信息传播真实性

| 回合 | 信息事件 | 传播范围 | 合理性 |
|------|---------|---------|--------|
| T1 | 发现预备队调动 | 仅玩家知晓 | ✓ |
| T2 | 玩家告知卢泰愚 | 玩家→卢泰愚（电话） | ✓ |
| T3 | 秘书官注意到玩家 | 秘书官→金载圭（内部汇报） | ✓ 有时间延迟 |

**没有出现"所有势力在同一回合同时行动"的问题**。

## 已解决的问题

1. **时代错误** — 五回合零时代错误（Round 3: T4有手机/短信）
2. **行动篡改** — 五回合行动忠实度全部 PASS（Round 3: T1/T3 行动被篡改）
3. **剧情过密** — Stage 1 输出严格遵守 ≤3事件 ≤3NPC 约束
4. **信息传播** — 信息按合理速度传播，无"瞬间全知"现象

## 仍存在的问题

1. **T2 篇幅超标**: 1258ch（目标900ch），对话场景的自然长度与篇幅限制存在张力
2. **T3 素材复制率偏高**: 52.6%，Stage 3 对 Stage 2b 素材复用过多
3. **T4 labeler 误判**: JSON_unknown calls=2，offscreen_npc_updates 的数组格式未被正确识别为 Stage 4b-ext
4. **T4 state_changes = 0**: 秘密会议场景未生成状态变化，可能因为 Stage 4b-core 判断无属性变动

## 结论

Round 4 的三项 prompt 优化（时代校验、行动忠实度、剧情密度控制）全部生效：
- 时代错误从有到无
- 行动篡改从 2/5 到 0/5
- NPC 和事件数量从失控到严格 ≤3
- 信息传播从瞬间全知到合理延迟

叙事质量整体提升，因果链五回合连贯，上下文逻辑合理。剩余问题集中在 Stage 3 的篇幅控制和素材重写率，属于叙事整合层的微调范畴。
