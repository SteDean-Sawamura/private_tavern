# 第五共和国剧本 第七轮五回合推演实验报告

## 实验背景

本轮测试（Round 7）在 Round 6 基础上针对叙事分析中发现的 6 个优化点进行了针对性修复：

| 编号 | 问题 | 优化措施 | 优化层 |
|------|------|---------|--------|
| L1 | 合并模式无时代约束 | `build_merged_stage2_prompt` 注入 world_background + 时代约束 | 代码 |
| L3 | "暗中""秘密"等行动方式被忽略 | Stage 1 user message 注入行动方式关键词提取 | 代码 |
| L4 | Stage 1 偶尔输出 JSON 前缀 | 后处理过滤 `[行动结果]` 之前的 JSON 数组 | 代码 |
| S1+S4 | 比喻过多 + 叙事开头非行动 | 少样本好段落替换为零比喻的对话驱动版本 | 示例 |
| S2 | 意象连续重复（军靴声5轮） | Stage 2a 注入上轮已用意象禁用列表 | 代码 |
| 跳过 | L2(监听闻)/S3(段落5感)/S5(过渡节奏) | 用户指定不优化 | - |

改动文件：`engine/prompt_builder.py`（合并模式、行动方式、意象历史、少样本更新）、`engine/game_session.py`（Stage 1 输出过滤）

## 结论

Round 7 的 6 项优化中 4 项验证生效（L1/L3/L4/S2），2 项效果有限（S1 少样本被合并模式绕过、结尾类型检测精度不足）。

**本轮最大收获**：
- 代码层优化（L1/L3/L4/S2）全部一次性生效，ROI 极高
- 叙事质量整体优秀，T3 的潜入场景和 T4 的对话场景达到很高水准
- 五回合因果链完整连贯，NPC 行为合理一致

**本轮最大问题**：
- **素材复制率严重回升**（60.7%→94.2%），Stage 3 的重写能力在对话密集场景中几乎失效。这是管线设计的结构性问题——当 Stage 2b 输出已经"足够好"时，Stage 3 倾向于保留而非重写
- **结尾类型检测**需要扩展启发式规则或引入更精确的分类方法

**下一步方向**：
- 素材复制率：可考虑在 Stage 3 的 system prompt 中明确要求"不得整段复制上游素材"，或在代码层添加重写率下限检查
- 结尾检测：扩展动作收束的关键词列表，增加"停""止""灭""散""消""响"等非主动动词
- 季节校验：在 Stage 2a user message 中注入当前游戏月份
- 合并模式少样本：在 `build_merged_stage2_prompt` 中追加精简版少样本示例
