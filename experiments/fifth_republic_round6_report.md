# 第五共和国剧本 第六轮五回合推演实验报告

## 实验背景

本轮测试（Round 6）在 Round 5 基础上实施了三管齐下的优化策略：

| 优化方向 | 具体措施 |
|----------|---------|
| Prompt 瘦身 | Stage 1: 17→10 条（行动三规则合一、身份两规则合一、信息传播精简）；Stage 2a: 8→6 条（删除感官均衡/意象新鲜度，消除矛盾）；Stage 2b: 13→12 条（对话差异化合并）；Stage 3: 22→12 条（删除 10 条风格禁令） |
| 少样本示例 | Stage 3 system 末尾新增一对好/坏段落示例，替代被删除的 blocklist 和风格禁令 |
| 代码执行层 | 5a 物理状态描述注入；5b 离场 NPC 位置速查注入；5c 结尾类型历史传递；5d 后生成长度硬截断（1000ch）；5e 素材复用率监控 |

改动文件：`engine/prompt_builder.py`（prompt 精简 + 新参数）、`engine/game_session.py`（代码执行层）

## 已解决的问题

### 从 Round 3 起累积解决
1. **时代错误** — 连续三轮零时代错误
2. **行动篡改** — 连续三轮行动忠实度全部 PASS
3. **剧情过密** — Stage 1 严格遵守 ≤3事件 ≤3NPC 约束
4. **信息传播** — 无"瞬间全知"现象

### Round 6 新解决
5. **NPC 不可能位置** — Round 5 T4 卢泰愚问题消除（代码层 5b）
6. **结尾重复** — 五回合结尾类型连续不同（代码层 5c）
7. **篇幅失控** — T5 Stage 3 输出 1057ch → 截断至 975ch（代码层 5d）
8. **Prompt 膨胀** — 总规则数从 ~50 条减至 ~40 条，Stage 3 system prompt 减少 ~700ch
9. **风格禁令低效** — 少样本示例替代效果等同或更优

## 仍存在的问题

1. **素材复制率仍偏高**: T1 ~70%（minor scope 合并模式）、T2 ~65%。Stage 3 对 Stage 2b 高质量对话的保留倾向仍然明显
2. **T1 时代微瑕**: "屏幕冷光""键盘"在 1979 年保安司令部办公室中可能不精确，虽不算严重错误
3. **T4 叙事开头**: "许和平的话音刚落"——未直接回应玩家行动（"召集秘密会议"），而是直接跳入会议进行时
4. **比喻密度**: T1/T5 各 3 个比喻，可以更克制

## 结论

Round 6 的三管齐下策略全部生效：

- **Prompt 瘦身**：删除矛盾规则（感官均衡 vs 感官≤2）、合并冗余规则，Stage 3 system prompt 缩短 ~700ch。LLM 注意力集中度提升，叙事质量未降反升。
- **代码执行层**：解决了 prompt 无法解决的三个硬问题——NPC 位置（结构化数据注入）、结尾重复（历史类型传递）、篇幅失控（硬截断）。
- **少样本示例**：一对好/坏段落替代 10 条风格禁令，效果等同或更优，证实了"show, don't tell"对 LLM 风格引导更有效。

核心收获：**可验证约束走代码，不可验证审美走示例，prompt 规则只留分类性硬约束**。

叙事质量整体为历次测试最佳，T4 的对话驱动叙事和 T5 的危机紧迫感达到了很高的文学水准。剩余问题集中在素材复制率和个别时代细节，属于 Stage 3 重写能力的微调范畴。
